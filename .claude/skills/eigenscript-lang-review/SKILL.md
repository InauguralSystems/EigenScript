# EigenScript language review

Read [`docs/SPEC.md`](../../../docs/SPEC.md) as the only normative language
specification. Use [`docs/SYNTAX.md`](../../../docs/SYNTAX.md) only as a
non-normative reading path. Do not infer a language rule from tutorials,
subsystem guides, old changelog entries, or implementation accidents; link the
exact `docs/SPEC.md` section when reporting a semantic claim.
