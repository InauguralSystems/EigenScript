- An assignment inside a function updates an existing outer binding whatever the function reads (`when is x`, `prev of x`, `what is x at L` and the other reads of a name's history), whether or not an inner function mentions the name, and, outside a comprehension's expression and a `catch` handler, whether or not the function also holds a comprehension variable or a `catch` name of that name (inside its handler a write to the `catch` name stays the handler's). Before, such a function wrote a binding of its own and the outer name kept its value. A function that relied on that must declare the name with `local` (#2474).
