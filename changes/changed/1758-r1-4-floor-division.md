- Add floor division `//` and `//=`, returning an exact int for two ints and a float otherwise. `%` now uses floor modulo with the divisor's sign. Integer floor-division overflow raises; `INT64_MIN % -1` is 0. A zero divisor raises when both operands are ints (`1 // 0`, `1 % 0`); with a float operand the result is, by default, the IEEE one (`1.0 // 0` is `inf`, `1.0 % 0` is `nan`), as for `/`, and `EIGS_STRICT=1` raises `value` for it (#1758).
