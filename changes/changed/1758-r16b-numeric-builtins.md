- Numeric builtins preserve exact int64 results and use exact integer arguments. `num` now refuses partial or empty numeric text (N10); JSON, store and database integer text decodes as int64 (N14). Scalar/list tensor arithmetic and shared counters raise on int64 overflow. Empty `min`/`max` now raises `value` in both call forms; `sign_extend` raises on subtraction underflow (R1.6b-D1/D2).
- EigenStore numeric lookup, update, and delete keys use all int64 digits (N5), including keys above 2^53. Fractional or out-of-range floats raise before record changes. Record integer text decodes exactly (N14); float persistence text remains unchanged until R1.7.
