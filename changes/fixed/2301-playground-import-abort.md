- The browser playground no longer dies on `import`: the WASM build now takes its C sources from the Makefile (it had lost `src/eigs_embed.c`) and fails to link on an undefined symbol, so an `import` reports an error instead of aborting the page's runtime. A runtime error or `exit of N` no longer leaves every later run in the page returning 1 with no output until a reload (#2301).
