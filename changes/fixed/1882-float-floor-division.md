- Float and mixed `//` and `//=` now use Python’s `divmod` quotient correction. Decimal boundaries such as `1.0 // 0.1` return `9.0`, and an underflowed negative ratio such as `1e-300 // -1e300` returns `-1.0`. Integer arithmetic is unchanged, and so are the errors for int `//` and `%` with an int zero divisor; a float `//` or `%` by zero gives the IEEE result (`inf`, `-inf` or `nan`) by default, and `EIGS_STRICT=1` raises `value` for it.
