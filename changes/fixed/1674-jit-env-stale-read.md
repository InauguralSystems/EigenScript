- Fixed a stale inline-cache read that mis-resolved an in-scope loop variable as `undefined variable` once the env freelist was bypassed (#1674, #1661 family). An env's `binding_version` is seeded from a monotonic counter at creation, so an env born at a freed env's reused address always carries a strictly greater `binding_version` than any inline cache cached against the prior occupant — the cache misses on address reuse instead of firing on the deterministic low-version collision that the freelist had been masking. The version token (`Env.binding_version`, the `EnvIC` cached versions, the loop-iter cache version, and the JIT-emitted load/compare sequences) is 64-bit and the birth counter is one process-wide relaxed-atomic counter advanced past freed envs' final versions, so it cannot wrap or collide across threads within any process lifetime (the prior per-thread `uint32` wrapped at ~2^32 env births — ~1.7h of sustained churn — reopening the ABA). New `EIGS_ENV_FREELIST_OFF` test seam forces that reuse on the default build for the regression gate; `EIGS_ENV_VERSION_SEED` starts the counter near 2^32 to exercise the boundary.
