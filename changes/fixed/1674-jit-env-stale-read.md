- Fixed a stale inline-cache read that mis-resolved an in-scope loop variable as `undefined variable` once the env freelist was bypassed (#1674, #1661 family). An env's `binding_version` is now seeded from a monotonic per-thread counter at creation, so an env born at a freed env's reused address always carries a strictly greater `binding_version` than any inline cache cached against the prior occupant — the cache misses on address reuse instead of firing on the deterministic low-version collision that the freelist had been masking. New `EIGS_ENV_FREELIST_OFF` test seam forces that reuse on the default build for the regression gate.
