- A float `at` line must be an exact whole number: `what is x at 8.5` raises `value` instead of answering line 8, and a non-finite or out-of-range float line raises `value` instead of answering `null`. The `when` ordinal is checked without an undefined cast. Audio generators (`audio_sine`, `audio_saw`, `audio_square`, `audio_noise`, `audio_sweep`) round `duration * rate` half away from zero instead of truncating it (#1758 R2.6, the #1746 residue).
