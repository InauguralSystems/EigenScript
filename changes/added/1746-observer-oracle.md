- `make observer-oracle` scores the observer against a corpus graded by mathematics (Hardy, NIST 6.4.4.2) and by stated conventions (numpy `isclose`, Keras `mode=min`, settling time). Each predicate is scored against one question; the labels are derived from per-sequence properties that `certify.py` certifies offline with sympy. Every row also runs as a loop under the interpreter, the default JIT and forced OSR, and the run measures the native share of the loop's assignments (predicate reads always run interpreted). Rows that need IEEE inf/NaN or exact int64 values run where the binary has them. A FINDING (tiers or forms disagree) or a wrong verdict on such a row fails the run, and with `FLOOR=tools/observer_oracle/floor.json` so does any verdict lost against the v0.46.0 tag (#1746, #1758). On the reference model, distance beats entropy as the signal (#1667).
